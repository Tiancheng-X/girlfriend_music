# 定调：形态 / 设置项 / 入口 / 范围

Type: grilling
Status: resolved

## Question

设置页的目的地定调：面板形态、设置项清单、入口位置、地图覆盖范围。

## Answer

2026-10-25 与用户 grilling 定稿：

1. **形态：设置面板 sheet** —— 玻璃拟态面板，交互语言与队列 sheet 一致（底部滑入 + 下拉关闭 + Esc，复用 spring 手势体系），不引入路由。
2. **设置项（四组全选）**：
   - 记住播放模式（列表/单曲/随机，localStorage 持久化，引擎 init 时读取覆盖）
   - 歌词字号（小/标准/大 三档，CSS 变量作用于主页面歌词面板）
   - 背景与动效开关（流体背景开关——关闭回退 CSS 氛围光晕；动效减弱开关——手动覆盖系统 reduced-motion）
   - 清除数据与关于（一键清除本地 localStorage 设置/缓存并刷新；关于区显示版本与说明）
3. **入口：播放页控制区** —— 队列按钮旁新增设置图标。
4. **地图范围：决策 + 执行** —— 推进到设置页上线、双端验收通过。
