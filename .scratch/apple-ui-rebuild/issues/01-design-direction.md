Status: resolved

## Question

重构的目的地定调：视觉主题方向、移动端信息架构、动效实现技术、地图覆盖范围。

## Answer

2026-10-24 与用户 grilling 首轮对齐，四项决策：

1. **视觉主题：Apple Music 风** —— 大封面沉浸布局、重玻璃拟态、更大胆的层次对比；主色可在现有青蓝 hue 165 基础上微调。
2. **移动端形态：全换苹果式** —— 两端统一为「底部半透明 mini-player + 全屏正在播放 sheet」，删除悬浮三态胶囊（disc / pill / bar 形态机整体退役）。
3. **动效实现：全用 Motion 库** —— 手势与过渡统一走 Motion 弹簧（可中断、速度交接、动量投影），不再手写 rAF 弹簧，也基本告别 CSS transition 驱动的运动。
4. **地图范围：决策 + 执行** —— 本图推进到「重构完成、构建通过」，执行票据直接改代码。
